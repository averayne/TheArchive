# The Archive

The Archive is a responsive, Bootstrap‑powered website created as a school project to showcase my interest in ARC Raiders, a cooperative PvE shooter developed by Embark Studios. This project served as my introduction to the Bootstrap framework and helped me understand how powerful and flexible the Bootstrap CDN can be for building clean, responsive layouts quickly.

## Project Overview
- This website highlights my hobby and enthusiasm for ARC Raiders. It includes:
- A responsive layout built with Bootstrap 5
- Official kit images sourced from Embark Studios
- Custom styling and structure to present game information in a clean, organized way

## Purpose
- Learn how to integrate and use the Bootstrap CDN
- Practice building responsive components
- Explore layout techniques such as containers, rows, columns, cards, and navbars
- Build a themed website around a game I enjoy

## Technologies Used
-HTML5
-CSS3
-Bootstrap 5 (CDN)
-JavaScript (optional, depending on your final implementation)
-Images from Embark Studios (ARC Raiders official kit assets)
